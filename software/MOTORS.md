# 电调与电机拆桨联调

当前 `Core/Inc/motor_config.h` 中 `MOTOR_STABILIZATION_ENABLED` 为 1，已启用 X 型四轴的横滚、俯仰角度 P → 角速度 PID → 电机混控计算，并按实测安装位置配置了 PWM 通道。初始增益未经实机调参，50Hz 传感器与电调控制链尚不是可飞行的闭环。测试前拆下全部螺旋桨，准备可随时断开电池的电源连接。

## 接线与输出

F411 TIM3 的 CH1/CH2/CH3/CH4 分别在 PB4/PB5/PB0/PB1。把各路接到对应电调的信号线，并让电调信号地与飞控地共地；电调 BEC 红线是电源输出，不接 MCU GPIO。四个 BEC 的供电并联方式应按实物电源设计核对。

PCB 原理图的 MOTOR1/2/3/4 依次对应 CH1/2/3/4。实测安装位置：左前 FL=MOTOR2/CH2，右前 FR=MOTOR1/CH1，右后 RR=MOTOR3/CH3，左后 RL=MOTOR4/CH4。此映射已写入 `Core/Inc/motor_config.h`。

拆桨检查 PID 时，在手机网页把 OLED 切到 STM32 数据页，再把 SW5 设为 `0100`（仅 SWITCH3 接通）。电机页显示实际解锁状态、`PID ACTIVE`/`PID IDLE`，以及 FR=MOTOR1/CH1、FL=MOTOR2/CH2、RR=MOTOR3/CH3、RL=MOTOR4/CH4 的 PWM 脉宽，单位为微秒。数值来自 TIM3 输出比较寄存器，约每 200ms 刷新一次；它不是实测转速。解锁并持续给非零油门后，缓慢倾斜机架即可比较左右或前后通道的变化。测试时必须拆下全部螺旋桨。

## 识别乱插的 PWM 线

1. **拆下全部螺旋桨**，固定机架。烧录新版 F411 和 ESP32 固件，手机连接网页并点击“开始控制”，保持“未解锁”、油门 0、三轴摇杆回中。
2. 依次**按住**网页 `CH1`、`CH2`、`CH3`、`CH4` 按钮。固件只让对应物理输出发 1250μs，其余保持 1100μs；松手或断线就回 1100μs。某只电机不转时，确认电调已经就绪，必要时只在 `Core/Inc/motor_logic.h` 小幅调整 `MOTOR_TEST_US`，先不要装桨。
3. 面向机头，从机体上方记录每个通道对应的是左前 FL、右前 FR、右后 RR、左后 RL 中的哪一只。记录旋向。物理通道与逻辑电机编号**不是** ArduPilot/PX4 的电机编号，按位置记录。
4. 若日后改动接线，在 `Core/Inc/motor_config.h` 中把 `MOTOR_OUTPUT_FL/FR/RR/RL` 改为对应通道的**零基编号**：CH1=0，CH2=1，CH3=2，CH4=3。四个值必须各不相同。线路无需重插。

本代码的 X 型布局及 yaw 混控符号采用从上方看 **FL、RR 顺时针（CW），FR、RL 逆时针（CCW）**，与你选定的旋向一致。旋向相反时，先断电，再通过电调设置或对调该电机的任意两根三相线调整；桨叶方向也必须匹配。当前 `STAB_YAW_RATE_P/I` 为 0，偏航闭环尚未启用。

自稳已启用。必须拆桨验证：机体左侧抬高时，右侧两路应比左侧两路增大；机头抬高时，后侧两路应比前侧两路增大。若方向不符，检查传感器安装方向、通道映射和混控符号，不要带桨尝试。`Core/Inc/stabilizer.h` 的 `STAB_MAX_TILT_DEG` 当前为 0，表示不再因横滚/俯仰角度过大而停机；改为正数可恢复对应阈值，例如 `35.0f`。自稳仍需要 100ms 内的新姿态样本；样本无效、通信失效或手动停机会锁定电机，必须再次执行停机→解锁序列。手机左杆油门现在松手保持，停机、停止控制、切后台或左杆触摸异常取消时归零；初始 PID 尚未调好，不能据此认定可悬停飞行。

默认 50Hz，每路 1100–1940μs，手机油门原码 0–4095 线性映射；端点在 `Core/Inc/motor_logic.h` 中修改。该范围采用好盈乐天 V2 手册列出的默认范围，但**实物型号未确认**，首次接电调前应先用逻辑分析仪或示波器检查脉宽与引脚顺序。旧版与 V2 参数可能不同。

上电输出 1100μs；手机必须先发送不解锁的有效帧，然后在油门不高于 40、其他三轴距中位不超过 160 时点击“请求解锁”。手机点停机、停发、断线超过 250ms 或主循环卡住，输出回到 1100μs 且锁定，必须先发送停机帧才能再次解锁。独立看门狗约 2 秒重启卡死的主控。网页显示的是**解锁请求**，不是飞控对实际解锁状态的确认。

## 行程校准

电调行程应与本固件的 1100μs 最小、1940μs 最大一致。当前固件为了避免意外启动，不提供上电直接输出最大油门的模式；使用**能独立供电并精确设置脉宽的舵机测试仪或 PWM 信号源**逐只校准。测试仪先供电并接好电调信号、信号地，再接电调动力电池，避免测试仪依赖电调 BEC 上电后才开始输出。核对信号源供电方式，勿让两个 5V 电源互相回灌。

1. 拆下所有螺旋桨。每次只接一只电调，确认电池节数符合该电调铭牌。
2. 信号源先持续输出 **1940μs** 最大油门，再给电调接入动力电池。
3. 听到确认最大端点的两声短鸣后，将信号源改为 **1100μs** 最小油门。V2 手册要求在两声短鸣后的 5 秒内完成这一步。
4. 等待电调确认最小端点、电池节数和就绪音，再断开电调动力电池。对其余三只重复。
5. 恢复飞控接线；先不接螺旋桨，确认上电始终为最小油门，随后只做短时低油门测试。记录每个接口对应的实际电机与转向。

若电调没有按相应手册的鸣音确认，停止操作，检查型号、供电、信号脉宽和接地，不要通过反复调大油门“试出来”。旧版和 V2 的鸣音与参数应以电调实物对应手册为准：

- [好盈乐天旧版 ESC 手册](https://support.hobbywingdirect.com/hc/en-us/article_attachments/29009668219155)
- [好盈乐天 V2 ESC 手册](https://www.hobbywing.com/en/uploads/file/20250930/64b726be7a56c9f415385f77683cdc46.pdf)

构建和烧录 F411：`make -C software -j4`、`make -C software flash`。手机端的解锁按钮也要求重新构建、烧录 ESP32，见 [ESP32 说明](esp32_oled/README.md)。
